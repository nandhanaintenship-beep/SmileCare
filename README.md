#Smile Care – Dental Clinic Management System

Developed by:
- Nandhana P Rajesh
- Dhanalakshmi Suresh

Smile Care is a web-based Dental Clinic Management System designed to make dental appointments and treatment management easier. Patients can register, log in, book appointments, and manage their dental visits. The system also helps dentists manage appointments and patient treatment information.

### Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Laragon

The project is developed as a simple and user-friendly system for managing dental clinic activities efficiently.
